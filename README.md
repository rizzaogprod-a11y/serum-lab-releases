# Serum Lab

Библиотека, прослушивание, анализ и подбор пресетов Serum 2 (и пресетов Serum 1, которые Serum 2 открывает), с генерацией новых пресетов по референсу из трека или по описанию словами.

- Каталог пресетов с поиском, категориями Serum, тегами, наборами и поиском дубликатов; исходные файлы пресетов только читаются.
- Прослушивание в один клик, игра с MIDI-клавиатуры или с клавиатуры компьютера.
- Анализ звука, поиск похожих по измерениям и карта звуков.
- Референс: перетащите WAV или AIFF, выделите звук и получите похожие пресеты или сгенерированное приближение.
- Варианты пресетов сохраняются отдельно и проверяются загрузкой в Serum 2.
- Работает локально, без интернета и платных сервисов (интернет нужен только для проверки обновлений).
- Само предлагает обновиться, когда выходит новая версия.

Нужен установленный Serum 2. Скачайте установщик в разделе [Releases](../../releases) или поставьте через лаунчер Nightbuild: https://get.nightbuild.workers.dev/

Установщик пока не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение при первом запуске: нажмите «Подробнее» → «Выполнить в любом случае».

Требуется Windows 10 (2004) или новее, 64-разрядная.
